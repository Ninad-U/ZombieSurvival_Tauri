# ZombieSurvival Game Builder


## Quick Start

1. Open a terminal in the ZombieSurvival folder
2. Run:
   ```
   python launch.py
   ```
3. The builder will automatically open in your browser

**Note:** Opening `index.html` directly with `file://` is not supported due to browser security restrictions.


## Overview
A 2D pixel-art post-apocalyptic zombie survival game builder.

## Features
- Game Builder/Editor for creating content
- Game Runtime for testing
- Entity/Component architecture
- Player and Enemy systems
- Combat system
- Developer Console (F3)
- Starter assets included

## How to Use
1. Open index.html in a browser
2. Use the left panel to navigate tools
3. Click "Create" buttons to spawn entities
4. Use WASD to move the player
5. Press SPACE or E to attack
6. Press F3 to toggle developer console

## Project Structure
- assets/ - Sprites and tiles
- data/ - JSON data files
- src/ - JavaScript source code
- examples/ - Example content
- docs/ - Documentation
